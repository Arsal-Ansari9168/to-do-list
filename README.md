# To-Do List - Second Project

## 📌 Description

This is a simple To-Do List web application created using HTML, CSS, and JavaScript.

The project allows users to add and manage their daily tasks through a simple and user-friendly interface.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## ✨ Features

- Add new tasks
- Display tasks
- Simple and clean user interface
- JavaScript-based task management
- Responsive design

## 📂 Project Files

- `second.html` - Main HTML file
- `second.css` - Styling and design
- `second.js` - JavaScript functionality

## 🚀 How to Run

1. Download or clone this repository.
2. Open `second.html` in your web browser.
3. Start adding and managing your tasks.

## 🎯 Purpose

This project was created to practice HTML, CSS, and JavaScript fundamentals and improve frontend web development skills.
